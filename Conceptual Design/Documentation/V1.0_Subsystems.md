## List of Subsystems

1. Mechanical System
* Material selection and procurement
* CAD Design of frame and first model
 
2. Power System 
* What are the subsystem's voltage and current requirements (e.g. RF, I/O, MCUs)
* PCB routing constraints
* Power supply (battery) choice
* Analysis on battery life
     
3. Communication System
* Specific radio hardware needed
* How to interface with radios
* What protocol is used
* What the ground control station looks like
* Physical constraints (e.g. range, bandwidth)
* End-to-end flow of information diagram
* System architecture diagram
* Which requirement does it satisfy

4. Flight Management Unit
* Sensor requirements (IMU (Accelerometer & Gyroscope), Magnetometer, Barometer/ToF Sensor, GPS)
* Sensor Fusion (EKF) for state estimation
* PID Control Loop for control signal generation
* Interface with ESC for actuator control
  
5. Companion Computer
* Decision on DIY Flight Controller?
* Various options tailoring from price, power consumption and overall Ai usage.
